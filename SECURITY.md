# Security

Current supported series: 2.x, on Python 3.11+ with Pillow 13. Keep external RAR backends current.
Inspect the repository Security tab for available reporting options. Avoid placing
sensitive files or exploit details in public issues. Archive and pixel limits reduce
resource exposure; this local audit is not a sandbox or a universal malware verdict.
See README and TESTING for the scoped Pillow Arrow advisory assessment and native-tool limits.
